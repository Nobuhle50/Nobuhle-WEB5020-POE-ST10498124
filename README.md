## 1. Project Title
Hlehle’s Orphanage – Non-Profit Organisation Website

## 2. Project Overview
This project is a multi-page responsive website created for Hlehle’s Orphanage, a non-profit organisation based in Hatfield, Pretoria. The website aims to raise awareness about the orphanage, share information about its programmes, encourage sponsorships and donations, and provide clear contact details.

The website was developed in stages:
- **Part 1** focused on planning, content research, semantic HTML structure, navigation and basic content.
- **Part 2** focused on visual design using an external CSS stylesheet, layout techniques (CSS Grid and Flexbox), typography, colour, pseudo-classes and full responsive design.

## 3. Website Goals and Objectives
- Create a functional and visually appealing website that meets the needs of a non-profit organisation.
- raise awareness about orphanage 
- provide clear information about programmes and how to help
- Make the website easy to navigate, informative and engaging.
- Encourage visitors to support the orphanage through sponsorships and donations.
- Ensure the website works well on desktop, tablet and mobile devices.
- Apply modern web development practices using semantic HTML5 and external CSS.

## 4. Key Features and Functionality
- Multi-page website (Home, About Us, Events & Programs, Sponsorship, Contact)
- Consistent navigation menu on every page
- Semantic html structure (`header`, `nav`, `main`, `section`, `footer`)
- External CSS stylesheet linked to all pages
- CSS Grid layout for card sections
- Flexbox used for header and navigation
- Responsive design using `@media` breakpoints
- Hover effects using CSS pseudo-classes
- Visual project timeline created with CSS
- Clear calls-to-action for sponsorship and contact

## 8. Part 2 – Designing the Visuals: CSS Styling and Responsive Design

### 8.1 External Stylesheet
- Created an external CSS file: `style.css`
- Linked the stylesheet to every HTML page using:
  ```html
  <link rel="stylesheet" href="style.css">

### 8.2 Default / Base Styles
Applied a CSS reset for consistent browser rendering
Set default font family, font size, line-height and colours
Established a clean base style for the entire website

### 8.3 Typography
Used clear heading hierarchy (h1, h2, h3)
Improved readability with suitable font sizes and line-height
Applied consistent text colours that match the brand

### 8.4 Layout Structure
Used CSS Grid (class selector .cards) for the card sections
Used Flexbox for the header and navigation
Applied grid-column: span and grid-row: span to control how many columns/rows certain cards occupy
Added multiple div wrappers as required for structure

### 8.5 Visual Styles (Decoration & Colour)
Colour scheme:
Primary blue: #1a365d and #2b6cb0
Accent orange: #ed8936
Light backgrounds for content sections
Added box shadows, border-radius and hover effects for a modern look
Created a clear visual hierarchy

### 8.6 Pseudo-classes
Used :hover on navigation links and buttons
Used :hover on cards to create interactive feedback
Improved user experience with smooth transitions

### 8.7 Responsive Design
Breakpoints were created using @media queries:
Tablet – @media (max-width: 768px)
Mobile – @media (max-width: 480px)
Responsive adjustments include:
Grid changes from 3 columns → 2 columns → 1 column
Navigation becomes stacked on smaller screens
Timeline switches to a single-column layout on mobile
Buttons and spacing adjusted for smaller screens
Images and text remain readable on all devices

### 8.8 Visual Timeline
A CSS-based visual timeline was added to show the project development milestones. It uses positioning, pseudo-elements and responsive adjustments.
